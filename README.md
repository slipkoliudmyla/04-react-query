# Пошук фільмів

Навчальний застосунок на React і TypeScript для пошуку фільмів через TMDB API.

TanStack Query отримує та кешує дані окремо для кожного пошукового запиту й сторінки. React Paginate перемикає сторінки результатів. Попередні результати залишаються видимими під час завантаження наступної сторінки.

Картка фільму відкриває модальне вікно з описом, датою виходу та рейтингом. Вікно закривається кнопкою, натисканням Escape або кліком на фон. Для фільмів без постера відображається текстова заглушка.

Порожній запит і відсутність результатів супроводжуються повідомленнями. Під час запитів відображається індикатор завантаження, а при помилці — повідомлення про неї.

## Запуск

Потрібні Node.js 24 або новіша версія та npm. Додайте персональний API Read Access Token до серверної змінної середовища `TMDB_TOKEN`. Запити проходять через маршрут `api/movies.ts`, який додає заголовок авторизації та передає номер сторінки до TMDB. Для локального запуску цей самий запит обробляє проксі Vite. Також підтримується серверний ключ `TMDB_API_KEY`.

Також підтримується прямий доступ до TMDB через персональний API Read Access Token у змінній середовища Vite `VITE_TMDB_TOKEN`.

```bash
npm ci
npm run dev
```

## Перевірка та збірка

```bash
npm run lint
npm run format:check
npm run build
```

Для Vercel використовується команда збірки `npm run build`, каталог результату `dist` та серверна змінна середовища `TMDB_TOKEN`. Пагінація охоплює до 500 сторінок результатів, які доступні через TMDB API.

Початковий код — репозиторій `sofiiadorosh/04-react-query`, наданий як основа навчального проєкту. Стек застосунку — React, TypeScript, Vite, TanStack Query, Axios, React Paginate, React Hot Toast, CSS Modules та modern-normalize.
